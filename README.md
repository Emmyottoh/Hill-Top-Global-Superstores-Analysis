# Hill-Top Global Superstores: Executive Performance Suite

This repository documents the end-to-end development of the **Hill-Top Global Superstores** business intelligence project.

## Project Overview
This project was developed to create a robust, interactive dashboard capable of tracking retail performance, product category distributions, and operational profit margins. It provides stakeholders with a clear, executive-level view of business health.

## Data Cleaning & Transformation
A core focus of this project was data integrity. 
* **Raw Data:** Started with a retail dataset containing 1,041 rows.
* **Data Cleaning:** Identified and removed 140 duplicate transactions under the Transaction ID field.
* **Final Output:** Successfully processed a clean, reliable dataset of 901 rows for analysis.

## Technical Stack
* **Power BI:** Interactive dashboard design and multi-page reporting.
* **Excel:** Preliminary data structuring and mapping of PivotTables.
* **ETL:** Automated data cleaning and pipeline construction.
* **DAX:** Advanced metric creation for financial calculations.
